# T-DT 后端源码快照

本目录来自 [mozihe/z-localization](https://github.com/mozihe/z-localization)，固定版本与补丁信息见 [UPSTREAM.md](UPSTREAM.md)，许可见 [LICENSE](LICENSE)。

本集成使用 Ubuntu 24.04 / ROS 2 Jazzy，安装、构建和 Adaptive-LIO 联合运行请遵循[仓库安装说明](../../README.md)。

[后端接口与地图工具](src/backend/README.md)保留上游说明，其中 Humble 是上游环境；本仓库不包含 ZLIO 前端。后端默认原始配置保留用于追溯，ADA 联合入口使用 `src/Adaptive-LIO/config/tdt_backend.yaml`。
