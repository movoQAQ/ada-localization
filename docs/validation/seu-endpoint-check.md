# SEU library 原始首尾位置核查

结论：原始点云支持录制首尾回到同一地点附近，不支持首尾实际相距32m。首末原始帧独立几何配准得到约0.16～0.17m平移；这是配准估计，不是测量真值，不能据此报告厘米级定位精度。

输入为此前下载、校验并记录SHA256的 `/workspace/datasets/seu-library.bag`，仅包含IMU和点云，没有真值位姿。提取第0、10、20、50、4247、4277、4287、4297帧，保留有效tag、有限坐标和0.5～80m范围内的点，没有使用前端估计姿态、导航Z裁剪或后端校正。

首帧header时间1777273012.000211954，末帧1777273441.700602055，相隔429.700390101秒。前者13,691点，后者13,246点。每帧约0.1秒，未去畸变；采样、动态物体、遮挡和帧内运动限制了精确测距能力。

方法：Open3D FPFH特征与RANSAC全局配准，0.5m体素、1.0m粗匹配阈值；随后0.5/0.2/0.1m多尺度点到平面ICP。三个随机种子11/29/47，不使用LIO平移或航向初值。以原始筛选点计算双向最近点重叠和残差。

| 配对 | 估计平移 | 0.5m内双向重叠率 |
|---|---:|---:|
| 末帧→首帧，三个种子 | 0.16886m | 63.98% / 61.80% |
| 首帧→末帧，反向独立配准 | 0.16107～0.16140m | 61.43～61.45% / 63.66～63.67% |
| 末帧→第10帧（起始约1秒） | 0.16721m | 59.07% / 58.55% |
| 倒数第11帧→第10帧 | 约0.52m | 61.79% / 60.76% |
| 倒数第21帧→第20帧 | 约2.04m | 56.87% / 62.26% |

首尾正反变换组合的平移残差约0.0161m、旋转残差约0.384°。前后各5秒处的配对（4247→50）出现不同局部解、低重叠，不将其当作成功验证，也不选取它宣称首尾不闭合。

额外留出验证：随机将首末各帧分成两半，仅用训练半点云完成全局配准与ICP，再对未参与拟合的半点云评价。平移0.16358m；0.5m内重叠57.65% / 55.44%，匹配点RMSE0.247/0.251m；1m内重叠73.24% / 69.82%。这是点级留出，不是独立传感器真值。

可视化 `seu-endpoint-overlap.png` 为留出实验变换应用于全帧后的XY/XZ/YZ投影，显示建筑和地面结构重叠。数值详见 `seu-endpoint-registration.json` 和 `seu-endpoint-heldout.json`。

复现：安装open3d和matplotlib到已有数据venv；运行 `tools/check_seu_endpoints.py --extract`，再以 `OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2` 运行同脚本（不带--extract），最后运行 `tools/validate_seu_endpoint_match.py`。输入/输出路径固定在 `/workspace/datasets`，脚本不会修改原包或LIO代码。

原先在线位姿首尾32.08m与这里原始传感器首末帧不是完全相同的评价对象，仍需保存最终优化轨迹做严格对齐评价；但第10帧对末帧同样近邻，起步约1秒的窗口差异不能解释32m。现有证据足以排除“该数据本来首尾就差约32m”作为合理解释。它不能单独确定初始化、前端匹配或回环失效各贡献了多少误差。
